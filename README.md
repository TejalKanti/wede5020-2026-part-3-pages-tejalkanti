## Project Overview

The Sphere Style Boutique App is a website application developed as part of an assignment in the WEDE subject. This application was created using HTML. The websites primary purpose is to allow users to create and buy outfits based on different styles and trends they like or would like to follow.

The website was developed to meet the requirements of the assignment, which includes creating a functional website application and utilizing GitHub for version control and CI/CD automation using GitHub Actions.

---

## Purpose and Features

### Purpose:
The main purpose of this app is to create and buy outfits based on different styles and trends. 

### Key Features:
Feature 1: The home page is where it shows the main details of what the application is about.

Feature 2: The about page is where it shows all the information about the business.

Feature 3: The products page is where all the clothing items are which are ready for customers to buy.

Feature 4: The enquiry page is where the customers can ask for help and enquire for more advice depending on what they struggling with.

Feature 5: The contact page is where it has all the different mediums a customer can use to contact the business.

These features aims to provide an application that functions and allows the user to create and buy outfits.

## Design Considerations

The design of the Game Tester was based on the following key considerations:
1. **User Experience (UX)**: 
	The app was designed with the goal of providing an intuitive and easy-to-navigate user interface, ensuring a seamless user experience. 
2. **Responsiveness**: 
	The app was built to ensure it performs well on different screen sizes, with particular attention to device compatibility. 
3. **Simplicity**: 
	The design is minimalistic, focusing on core features without overwhelming the user. 
4. **Performance**: 
	Code optimization was considered to ensure fast response times and low battery usage.
